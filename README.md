## CN2 GIA 贵在哪：线路原理和 GT 的区别

搬瓦工的价格差，全部差在回程线路上。CN2 是中国电信的下一代承载网（AS4809），其中 GIA（Global Internet Access）是质量最高的一档，全程专线、专用带宽；而 CN2 GT 虽然也走 AS4809，2019 年之后拥堵严重，实际体验和普通 163 骨干网差距不大。买之前分清 GT 和 GIA，比看任何测速截图都有用——不少便宜套餐标着"CN2"，实际是 GT。

GIA 为什么贵？官方说法是向中国方向传输数据走 GIA 的 IP 转接成本可达 $120/Mbps，这是硬成本。代价除了价格，还有容量有限：遇到 DDoS 攻击时官方只能直接 nullroute（封锁 IP），没有清洗服务，这点对建站用户要心里有数。

DC6 CN2 GIA-E 机房的三网回程是：电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走 Premium（AS10099），三线都是各自运营商的高端回程，另带 Google 直连 peering。这也是它在大陆用户里口碑集中的原因。不过官方自己也建议：如果延迟不是关键需求，选洛杉矶 E-Commerce 套餐就够了——意思是别为用不上的线路多付钱。
